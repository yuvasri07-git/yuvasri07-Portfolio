# Yuvasri Vasamsetty — Cybersecurity Portfolio

A responsive, static portfolio built with HTML, CSS and JavaScript. It is designed for GitHub Pages and requires no build tools or framework.

## Files

- `index.html` — portfolio content and page structure
- `styles.css` — responsive light-theme styling
- `script.js` — mobile navigation and current-year footer
- `assets/favicon.svg` — simple site icon

## Run locally on Windows

1. Extract this folder.
2. Open the folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.

No `npm install` or build command is needed.

## Publish with GitHub Pages

1. Create a new **public** repository named exactly `yuvasri07-git.github.io`.
2. Upload the contents of this folder to the repository root. Make sure `index.html` is at the root, not inside another nested folder.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for the deployment to finish. The site should appear at `https://yuvasri07-git.github.io/`.

GitHub Pages can take a few minutes to publish the first time.

## Before publishing — verify these details

- Confirm the direct GitHub repository URL for **Network Traffic Analyzer & ARP Device Scanner** and replace the profile link in its project card in `index.html`.
- Check that every listed certification and training item is accurate and that its title matches the certificate.
- Add project screenshots only after capturing genuine screenshots from your own running projects.
- Review the email, LinkedIn and GitHub links.
- Do not publish private data, API keys, tokens, internal IPs, or screenshots containing sensitive information.

## Updating the portfolio

Edit the text in `index.html`. Change colors, spacing and layout in `styles.css`. Commit and push the changes to the `main` branch; GitHub Pages will redeploy automatically.

## Project scope and responsible use

The featured tools are educational projects. The scanner should only be used against systems and networks that you own or have explicit authorization to assess. The portfolio intentionally avoids claiming professional penetration-testing experience or unsupported performance metrics.
